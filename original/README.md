# Original prototype

`comp_funcs.py` and `DupsSurvey.ipynb` are the original 2023 blog-post
prototype this project is built from: hand-written by Andrew Wheeler, with
no AI assistance, prior to this repository. `src/surveymatch/` is a cleaned
up, tested, and extended Python package built from this same statistical
approach; see the root `README.md` and `paper.qmd` for the current method
and results.
